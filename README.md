# 100 AI Frameworks

This repository documents 100 AI frameworks, tools, and libraries with short, practical notes.

## Documentation

The docs site is built with MkDocs and published with GitHub Pages.

- Local docs source: `docs/`
- MkDocs config: `mkdocs.yml`
- Auto deploy: `.github/workflows/deploy-docs.yml`

## Run Locally

```bash
pip install mkdocs
mkdocs serve
```

Then open `http://127.0.0.1:8000`.
