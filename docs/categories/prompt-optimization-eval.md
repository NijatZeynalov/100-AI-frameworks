# Prompt Optimization & Evaluation

## Goal

Improve prompt quality, structured outputs, safety checks, and evaluation workflows for LLM apps.

## Problem Space

Prompt-as-code workflows, prompt optimization, schema-first outputs, guardrails, vulnerability testing, and prompt/model evaluation.
