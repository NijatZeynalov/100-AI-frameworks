## Problem

Large models are expensive to deploy because memory requirements remain high even when inference is otherwise feasible.

## How HQQ helps

Provides fast calibration-free Half-Quadratic Quantization for large models, including LLM and vision model workflows.

## Test project

Quantize a small open-source language model with HQQ and compare memory usage, throughput, and output quality against the original model.
