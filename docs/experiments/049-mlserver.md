## Problem

Production ML systems need a standard inference server for REST/gRPC serving, batching, multi-model hosting, and Kubernetes-native deployment.

## How MLServer helps

Provides an open-source inference server for machine learning models with V2 Inference Protocol support, multi-model serving, adaptive batching, and multiple runtimes.

## Test project

Serve a scikit-learn or Hugging Face model with MLServer and test REST/gRPC inference plus multi-model loading behavior.
