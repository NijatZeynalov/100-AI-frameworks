## Problem

Prompt engineering becomes hard to track when prompts are treated as loose strings instead of versioned programs.

## How ell helps

Provides a lightweight language model programming library that treats prompts as functions with versioning, tracing, evaluations, multimodal inputs, and a local studio.

## Test project

Build a versioned prompt workflow with traced calls, compare prompt versions, and inspect outputs in Ell Studio.
